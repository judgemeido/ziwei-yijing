## 1. 布局重构:一屏自适应 + 移动端
- **问题(已核实)**:星盘固定 760px,左栏「起盘 + 本命卦 + 读盘」竖向堆叠,常规屏(高≤900)一屏装不下。
- **桌面**:星盘尺寸改 `min(70vh, 56vw)` 自适应;左栏改为**分段标签**(起盘 / 本命卦 / 读盘)单块显示,减少竖高;整体目标首屏可见。
- **移动端(<720px)**:单列;星盘缩放到屏宽;起盘表单折叠为抽屉;读盘/结果为底部抽屉;触控目标 ≥44px;无横向滚动。
- **测试**:用浏览器 viewport 在 390×844 / 768 / 1280 / 1440 四档截图核验。

- **过去 / 未来 切换**(默认方案):

- 复用现有 64 卦义,过去/未来各给方向化提示。
