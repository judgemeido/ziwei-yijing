# 星枢 · 紫微斗数 × 易经 2D 星盘

以**紫微斗数十二宫(命座)**为核心、融合**易经**的纯前端 2D 命盘与卜卦体验。深空暗调玻璃质感,Apple 风克制美学。仅供文化娱乐,不构成任何决策建议。

## 技术栈
- TypeScript + Vite
- iztro(紫微斗数排盘)
- cnchar / cnchar-trad(姓名康熙笔画,用于梅花易数起卦)
- 原生 Canvas / SVG / CSS(圆形星盘、起卦仪式动效,无 3D 依赖)

## 功能
- 起盘:姓名 + 公历生辰 + 性别 → 圆形紫微星盘(后天八卦外环、十二宫、中宫太极与本命卦)
- 起卦仪式:道学·易经风格的缓和过渡动效 + 挂盘生成动效
- 卜卦:以姓名并卜卦时间梅花起卦,过去(互卦)/当下(本卦)/未来(变卦)三象切换,穿插《周易》卦辞与象传
- 本命:由出生起出的本命卦解读,穿插典籍
- 读盘:点选宫位看宫义、主星「星×宫」、四化、三方四正与推导综论;附命盘使用方法
- 导出:占卜结果一键导出 PNG / PDF

## 开发
```bash
npm install
npm run dev        # 启动开发服务器(2D)
npm run build      # 类型检查 + 生产构建
npm run preview    # 预览构建产物
```
